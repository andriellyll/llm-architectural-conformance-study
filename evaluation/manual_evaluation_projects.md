# Projects Included in the Manual Evaluation Sample

The manual evaluation of generated ArchUnit tests (Section 3.2 of the paper) was performed on a stratistically representative random sample of 270 tests drawn from the full generation results. The sample was stratified by repository and covers the following 13 GitHub projects:

| Repository | GitHub URL |
|---|---|
| Cornutum/tcases | https://github.com/Cornutum/tcases |
| apache/fineract | https://github.com/apache/fineract |
| apache/inlong | https://github.com/apache/inlong |
| apache/jackrabbit-oak | https://github.com/apache/jackrabbit-oak |
| bitcoinj/bitcoinj | https://github.com/bitcoinj/bitcoinj |
| hyperledger/besu | https://github.com/hyperledger/besu |
| opensearch-project/OpenSearch | https://github.com/opensearch-project/OpenSearch |
| pentaho/pentaho-platform | https://github.com/pentaho/pentaho-platform |
| skiptests/astraea | https://github.com/skiptests/astraea |
| slackhq/kaldb | https://github.com/slackhq/kaldb |
| sqlancer/sqlancer | https://github.com/sqlancer/sqlancer |
| telstra/open-kilda | https://github.com/telstra/open-kilda |
| thingsboard/thingsboard | https://github.com/thingsboard/thingsboard |

The complete manual evaluation data (including LLM-as-a-Judge scores, human annotations, mutation test results, and annotator agreement columns) is available in `evaluation/manual_evaluation_results.csv`.
